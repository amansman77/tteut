# 뜨읏 (Tteut)

> 사람의 언어를 성장시키고, 그 언어로 나를 만들어가는 플랫폼

---

## 🧭 Vision

뜨읏은 단순한 AI 서비스가 아니다.
사람이 **자신의 언어를 발견하고, 인식하고, 몸에 베게 하여, 결국 자신을 만들어가는 과정**을 돕는 플랫폼이다.

> 삶의 의미를 찾는 것이 아니라, 삶이 곧 의미다.
> 그리고 그 의미는 **언어를 통해 드러난다.**

---

## 💡 Problem

사람은 언어로 사고한다.
하지만 대부분의 사람들은 자신의 상태를 정확하게 표현하지 못한다.

* “짜증난다”
* “기분이 안 좋다”
* “왜 이런지 모르겠다”

이처럼 낮은 해상도의 언어는
→ 흐릿한 사고
→ 감정 혼란
→ 비효율적인 선택으로 이어진다.

👉 문제는 지능이 아니라 **언어 해상도**다.

---

## 🎯 Solution

뜨읏은 사람의 언어를 다음과 같은 과정으로 성장시킨다:

1. **알아내기 (Discovery)**

   * 아직 표현되지 않은 감정과 생각을 끌어낸다

2. **알아차리기 (Awareness)**

   * 그것을 명확한 언어로 구조화한다

3. **몸에 베게 하기 (Embedding)**

   * 반복과 실천을 통해 언어를 행동으로 연결한다

4. **나를 만들어가기 (Identity Formation)**

   * 축적된 언어가 결국 ‘나’를 형성한다

---

## 🔄 Core Loop

```
감정 → 언어화 → 인식 → 반복 → 정체성
```

뜨읏은 이 루프를 지속적으로 반복시키는 시스템이다.

---

## 🧱 Platform Structure (다움)

뜨읏은 ‘다움’ 플랫폼의 일부로 다음 서비스들과 연결된다:

* **벗 (Buddy)** → 감정과 생각을 끌어내는 대화 인터페이스
* **뜨읏** → 언어 구조화 및 의미 체계
* **단단이** → 반복과 실천 (행동 기반 강화)
* **시간의 봉투** → 시간 축 기반 기록 및 회고

👉 언어 → 사고 → 행동 → 시간
전체를 하나의 흐름으로 연결한다.

## 🚀 Growth Strategy

### 1. SEO 기반 Growth Artifact

초기 전략은 앱이 아니라
👉 **검색 기반 경험 진입점 (Growth Artifact)** 구축이다.

> 사용자가 문제를 느끼는 순간 → 바로 뜨읏을 경험

---

### 🎯 First Artifact: 감정 → 언어 변환기

#### 개요

사용자가 입력한 감정을
더 높은 해상도의 언어로 변환해주는 도구

#### 예시

* 입력:
  `짜증난다`

* 출력:

  * “내 기대와 현실의 간극에서 오는 피로감”
  * “통제되지 않는 상황에 대한 불편함”
  * “반복되는 상황에 대한 무력감”

---

### 🔍 User Flow

```
검색 → 랜딩 → 입력 → 결과 경험 → 공유
```

---

### 🧪 Success Metric

* 결과를 보고 “이거 뭐지?”라는 반응이 나오는가
* 사용자가 결과를 공유하는가
* 재방문이 발생하는가

---

## 🛠 Tech Stack (Proposed)

* **Frontend**: Next.js (SEO 최적화)
* **UI**: React
* **Backend**: Hono
* **Runtime**: Cloudflare / Edge
* **AI**: LLM (local or API 기반)

---

## 🎯 MVP Scope

초기 MVP는 단 하나의 경험에 집중한다:

> “한 번의 사용으로
> 내가 어떤 상태인지 더 정확히 이해하는 경험”

### 구성

* Input: 감정 또는 문장 입력
* Processing: 언어 해상도 확장
* Output: 3~5개의 더 정교한 표현
