# ADR-PROD-001 MVP 범위: 감정 → 언어 변환기 단일 경험에 집중

## 상태
Draft

## 맥락
뜨읏의 궁극적 비전은 "언어 해상도를 성장시켜 자기 정체성을 만들어가는 플랫폼"이다.
하지만 이 비전을 한 번에 구현하려 하면 검증 없이 많은 것을 만들게 된다.

초기에 결정해야 할 것은:
- 어떤 한 가지 경험이 뜨읏의 핵심 가치를 가장 잘 보여주는가
- 그 경험으로 사용자 반응을 어떻게 검증할 것인가

## 결정
MVP는 **"감정 → 언어 변환기" 단일 경험**에만 집중한다.

**MVP에 포함:**
- 감정/상태를 한 줄로 입력
- AI가 3~5개의 더 정교한 언어 표현으로 변환
- 결과 공유 기능 (텍스트 복사)

**MVP에서 제외:**
- 사용자 계정 / 저장 기능
- 언어 성장 히스토리 추적
- 벗(Buddy), 단단이 등 연결 서비스
- 감정 분류 / 태깅

## 근거
- 뜨읏의 핵심 가치 ("낮은 해상도 → 높은 해상도 언어")를 가장 직관적으로 체험할 수 있는 형태
- 구현 복잡도가 낮아 빠른 사용자 반응 수집 가능
- 공유 기능을 통해 바이럴 가능성 내재
- 저장/계정 없이도 핵심 가치 전달 가능 → 인프라 부담 없이 가설 검증

**포기한 대안:**
- 온보딩 + 히스토리 포함한 풀 서비스 → 검증 전 과투자
- 감정 분류 UI → 입력 허들 증가, 핵심 경험 희석
