# ADR-PROD-003 익명 입력 기반의 살아낸 뜻 수집 구조

## 상태

승인

## 맥락

PoC 단계에서 가장 중요한 것은
사용자가 실제로 자신의 살아낸 뜻을 입력하는지 검증하는 것이다.

현재는 질문에 대한 답변이 저장되지 않아
서비스 자산으로 축적되지 않고 있다.

회원가입 중심 구조는 초기 이탈을 크게 증가시키므로
입력 장벽을 최소화할 필요가 있다.

## 결정

로그인 없이 익명으로 입력을 받고
사용자의 답변을 즉시 저장한다.

입력 데이터는 모두 저장하되
공개 여부는 운영자가 후처리한다.

수집은 느슨하게,
노출은 엄격하게 운영한다.

## 근거

PoC 단계에서는
좋은 데이터 관리보다
실제 입력 행동 검증이 우선이다.

회원가입은 초기 사용자 유입을 막는 가장 큰 장벽이며
서비스 검증 자체를 어렵게 만든다.

스팸이나 품질 문제는
status 기반 운영 검수로 해결 가능하다.

초기 플랫폼은
기능보다 데이터 밀도가 더 중요하다.
