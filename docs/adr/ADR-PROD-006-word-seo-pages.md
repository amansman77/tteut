# ADR-PROD-006 공개 단어 페이지(`/word/[slug]`) 기반 SEO 자산 구조

## 상태

승인

## 맥락

뜨읏은 사람의 언어를 성장시키는 플랫폼이며,
초기 성장 전략의 핵심은 SEO에 노출되는 Growth Artifact를 만드는 것이다.

운영자는 `/seed`를 통해 살아낸 뜻을 작성하고 있지만
현재 구조는 `seed → DB 저장`까지만 존재한다.

즉, 데이터는 저장되지만 Google이 읽을 수 있는 공개 URL이 없다.
`/seed`는 데이터 입력 도구(CMS)일 뿐, SEO 자산 자체는 아니다.

## 결정

입력된 살아낸 뜻을 기반으로 공개 단어 페이지 `/word/[slug]`를 생성한다.

예:
- /word/존중
- /word/기다림
- /word/책임
- /word/사랑

페이지 구성:
```
단어
사전적 의미
살아낸 뜻들
내게 이 단어는… (사용자 입력 영역)
```

구조:
```
/seed = CMS
/word/[slug] = Public SEO Asset
```

## 근거

DB에만 존재하는 데이터는 검색되지 않는다.
Google은 공개 URL, HTML 콘텐츠, 메타 정보, sitemap을 기준으로 인덱싱한다.

뜻 500개 + URL 1개 보다
뜻 100개 + URL 100개가 훨씬 강한 SEO 자산이다.

뜨읏의 성장은 페이지 단위로 발생한다.
PoC 단계에서도 기능보다 먼저 공개 자산을 만드는 것이 중요하다.

## 결과

(운영 후 기록)

- 생성된 `/word/*` 페이지 수
- Google Search Console 인덱싱 수
- 검색 유입 발생 여부
- 주요 단어 검색 노출 순위
- `/word/*` 기반 사용자 재방문 비율
